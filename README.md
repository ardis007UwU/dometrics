[![Release](https://img.shields.io/github/v/release/ardis007UwU/dometrics?style=flat-square)](https://github.com/ardis007UwU/dometrics/releases)

[![CI/CD Release](https://github.com/ardis007UwU/dometrics/actions/workflows/release.yml/badge.svg)](https://github.com/ardis007UwU/dometrics/actions)

**Dometrics** is a zero-maintenance, single-binary C++20 developer telemetry daemon and CLI tool. It automatically monitors your active coding time using Linux `inotify` file system events and indexes lines of code (LOC) into a fast, local SQLite WAL database—100% offline with zero cloud tracking.

  Commits        : 7
